# Webapp to monitor SNMP devices with grafana dashboard

- Install [grafana](https://grafana.com/docs/grafana/latest/setup-grafana/installation/), [telegraf](https://docs.influxdata.com/telegraf/v1/install/) and [influxdb](https://docs.influxdata.com/influxdb/v2/install/?t=Linux) on ubuntu (>= 20.04)
- Import `snmp_dashboard.json` file into grafana to load the snmp dashboard.
- Run backend.py
- Run index.html
